# GalleryNest

GalleryNest is a Shopify app for product image gallery sliders.

## Features

- Product-specific slider activation from the app admin
- Main product image slider with thumbnail positions
- Thumbnail size and visibility settings
- Zoom icon controls and custom SVG support
- Variant image sync for product variant changes
- Theme app extension for storefront rendering

## Development

```shell
npm install
npm run dev
```

## Build Checks

```shell
npm run typecheck
npm run lint
npm run build
```
